# Portfolio capture manifest

Required screenshots or a short screen recording:

1. Analysis home with a natural-language question.
2. Data Evidence and Policy Evidence shown separately.
3. Pending Human Review with evidence snapshot.
4. Review decision and resumed analysis with the same request ID.
5. Payroll discrepancy/reconciliation with warnings and source evidence.
6. Policy upload metadata and ingestion status.

Capture only synthetic data. Generated PNG/MP4 files are local release assets
and are intentionally excluded from the repository; this manifest keeps the
portfolio claim reproducible without committing potentially stale binaries.
